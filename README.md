# StackUp Hold'em — Wraps

Tela inicial mobile-first para treinamento das principais modalidades de Omaha.

## Módulos

- Omaha Hi
- Omaha Hi-Lo (8 or better)
- Omaha de 5 Cartas
- Omaha de 6 Cartas 
- Courchevel

## Stack

- React
- Vite
- Tailwind CSS
- Lucide React

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

A interface foi otimizada principalmente para telas móveis entre 360 e 430 px, mantendo adaptação responsiva em larguras maiores.
